# 🚗 Automotive Mechanical Fault Detection Using AI

## 📌 Project Overview

This project focuses on the early detection of automotive mechanical faults using **sound analysis and artificial intelligence**.

The system captures sounds generated by a vehicle, processes the audio signals, converts them into **Mel-spectrograms**, and uses a **Convolutional Neural Network (CNN)** to classify different mechanical conditions.

The project was developed as part of my **Master's Final-Year Project (PFE)** in Embedded Systems.

## 🎯 Objective

The main objective is to explore a non-invasive approach for detecting mechanical faults before they lead to more serious failures.

The system was designed to classify:

* Normal engine/vehicle sound
* Defective driveshaft (cardan)
* Worn clutch
* Low engine oil
* Belt whistling
* Turbo whistling

## 🔧 Embedded Prototype

The prototype integrates:

* Raspberry Pi 5
* 3 × MAX9814 microphones
* MCP3008 ADC
* 20×4 I2C LCD
* PCF8574 I2C interface

The Raspberry Pi is used to acquire and process the audio signals and to run the embedded prototype.

## 🤖 Machine Learning

The audio dataset was collected from different sound sources and prepared for training.

Main processing steps:

* Audio segmentation
* Noise and signal preprocessing
* Mel-spectrogram extraction
* Image resizing
* CNN training and evaluation

The final CNN model was selected after comparing different approaches.

## 📊 Results

The CNN model achieved approximately **72% classification accuracy** on the evaluated dataset.

The project remains a prototype and is intended as a proof of concept for sound-based automotive fault detection.
